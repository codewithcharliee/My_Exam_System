# Accessibility statement

The examination and dashboard workflows use a skip link, page and navigation landmarks, labelled controls, keyboard focus indicators, live status regions, semantic table headers, descriptive button names, and question navigation labels. Response word counts and connection states are announced through polite live regions. Colour is not the only signal for connection, synchronization, issue, or review status.

The exam timer remains visible and response entry remains available when connection status changes. Browser monitoring continues to suppress context menus and selected shortcuts because these controls are part of the examination integrity requirements. The implementation does not claim that browser-level restrictions prevent every operating-system capture or assistive technology behavior. Screen reader behavior should be verified with the browser and assistive technology combinations used by the institution.
